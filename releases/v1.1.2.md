# v1.1.2

First release on this distribution repo after reset. Desktop agent **1.1.2**; pair with mobile on [Google Play](https://play.google.com/store/apps/details?id=com.billten.remoteterminal) or the [App Store](https://apps.apple.com/pk/app/remote-terminal-pro/id6771671841).

## Desktop downloads

- `Remote-Terminal-1.1.2-Windows-x64.zip` — portable
- `Remote-Terminal-1.1.2-Windows-x64-Setup.exe` — NSIS installer
- `Remote-Terminal-1.1.2-WinNT-x64.exe` — WinNT installer
- `Remote-Terminal-1.1.2-macOS-arm64.dmg` — Apple Silicon (via Actions workflow)
- `Remote-Terminal-1.1.2-macOS-x64.dmg` — Intel (via Actions workflow)

## Highlights

- QR pairing, join password, cloud and local network modes
- Remote shell (CMD/PowerShell on Windows; bash/zsh on macOS)
- Remote files and optional clipboard sync (phone ↔ PC)
- Session restore on mobile; tray dashboard on desktop

## macOS builds

After this release is published, run **Attach macOS builds to release** on [remote-terminal-app](https://github.com/w3sourcecode/remote-terminal-app/actions) with tag `v1.1.2` and `source_ref` pointing at the commit that has `desktop/package.json` version **1.1.2**.
