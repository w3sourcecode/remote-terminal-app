# v1.1.2

Desktop agent **1.1.2** built from **`feature/performance-fixes`** on `w3sourcecode/remote-terminal`. Pair with mobile on [Google Play](https://play.google.com/store/apps/details?id=com.billten.remoteterminal) or the [App Store](https://apps.apple.com/pk/app/remote-terminal-pro/id6771671841).

## Desktop downloads

All assets are attached to this release (direct download from the **Assets** section or [README Downloads](https://github.com/w3sourcecode/remote-terminal-app#-downloads)):

| Platform | File |
|----------|------|
| Windows portable | `Remote-Terminal-1.1.2-Windows-x64.zip` |
| Windows NSIS | `Remote-Terminal-1.1.2-Windows-x64-Setup.exe` |
| Windows WinNT | `Remote-Terminal-1.1.2-WinNT-x64.exe` |
| macOS Apple Silicon | `Remote-Terminal-1.1.2-macOS-arm64.dmg` |
| macOS Intel | `Remote-Terminal-1.1.2-macOS-x64.dmg` |

macOS DMGs are produced by the **Attach macOS builds to release** workflow (`source_ref=feature/performance-fixes`).

## Highlights

- QR pairing, join password, cloud and local network modes
- Remote shell (CMD/PowerShell on Windows; bash/zsh on macOS)
- Remote files and optional clipboard sync (phone ↔ PC)
- Session restore on mobile; tray dashboard on desktop
