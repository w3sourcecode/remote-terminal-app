## What's new

- **Windows:** Shell processes (cmd/PowerShell/conhost) are cleaned up when a remote session ends — no more orphaned hidden terminals in Task Manager.
- **Windows dev:** Fixed a build error that blocked `npm run dev` after UAC elevation.
- **Stability:** Improved session hub lifecycle and connectivity handling.
