# v0.1.14

Desktop agent and documentation refresh. Pair with mobile **1.3** (Android) / **Remote Terminal Pro** (iOS).

## Desktop downloads

Upload these assets to the GitHub release (build from `remote-terminal` with `desktop/package.json` version **0.1.14**):

- `Remote-Terminal-0.1.14-Windows-x64.zip`
- `Remote-Terminal-0.1.14-Windows-x64-Setup.exe`
- `Remote-Terminal-0.1.14-WinNT-x64.exe`
- `Remote-Terminal-0.1.14-macOS-arm64.dmg` (CI: **Attach macOS builds to release**)
- `Remote-Terminal-0.1.14-macOS-x64.dmg`

## Highlights

- Join password change on PC: mobile clears stale password and prompts for the new one
- Clipboard sync (phone ↔ PC, opt-in on both sides)
- Remote files: path bar, improved uploads
- Terminal: keep screen on during long commands; better `ping` / Ctrl+C handling
- Session reconnect and Home connect UX improvements

## Build notes

1. Set `desktop/package.json` to `0.1.14` (must match tag `v0.1.14`).
2. Windows: `npm run build:win`, `build:winnt`, portable zip script from `desktop/`.
3. macOS: publish release tag, then run workflow **Attach macOS builds to release** with `source_ref` pointing at the release branch/commit.
